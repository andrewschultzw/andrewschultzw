## 🖥️ The Homelab

Running a self-hosted stack on an HP Z640 (dual Xeon, ECC RAM) with Proxmox VE as the hypervisor. LXC containers all the way down.

Current services include:

- **Nginx Proxy Manager** + **Cloudflare Tunnel** — zero-trust reverse proxy setup
- **Grafana + Prometheus** — monitoring the things that monitor the things
- **Jellyfin + Immich** — media & photo management backed by a Synology NAS
- **Astro + Directus** — personal site & headless CMS
- **Paperless-ngx + Actual Budget** — because adulting requires infrastructure too
